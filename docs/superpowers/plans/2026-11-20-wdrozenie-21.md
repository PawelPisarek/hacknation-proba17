# Zadanie 21 — wdrożenie strona + usługa na karcie: plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** hacknation.ksefbot.pl przyjmuje własny `.bmp` (do ~50 MB) i partię pokazową, liczy na karcie OMENa przez usługę HTTP; to samo działa lokalnie bez sieci.

**Architecture:** `usluga/` — Python `http.server` trzymający biblioteki wzorców na karcie, woła istniejący `przeswit` (v1/v2/v3); startuje jako zlecenie orkiestratora `gpu-tlo`, kończy po `--bezczynnosc` min. `strona/` — Node 22 bez zależności, pliki statyczne + przekazanie `/api/*` do `OMEN_URL`, wdrażana przez Coolify. `wdroz.sh` spina oba.

**Tech Stack:** Python 3 + torch (istniejący venv `~/venv` konta `hackathon`), `unittest` (stdlib), Node 22 (`node --test`), Docker (Coolify), orkiestrator.

**Spec:** `docs/superpowers/specs/2026-11-20-wdrozenie-21-design.md` (+ `docs/zadania/21-wdrozenie-strona-i-usluga.md`, spec §3, A12, A14).

## Global Constraints

- Ciężkie liczenie wyłącznie na karcie OMENa przez orkiestrator (`--klasa gpu-tlo --rdzenie 2 --konto hackathon`, bez `--wylaczne`); testy bez karty `--maszyna dowolna --klasa testy`. Nic na Macu, nic na CPU serwera.
- Usługa: port 8770, `--bezczynnosc 10` domyślnie (0 = bez końca, tylko na pokaz jury).
- Wgrywania własnego pliku nie wycinamy (P43). Limit ciała 120 MB.
- Strona po polsku, bez zewnętrznych skryptów/fontów/adresów (offline).
- Nie ruszać: `src/przeswit/*`, `dane/*`, `ocena/*` (tylko czytamy), pliki zadań 22–29 Programisty.
- Wdrożenie (Coolify `/deploy`, zmiana repo aplikacji) tylko z `POMIN_WDROZENIE=1` za zgodą Pawła.
- Komenda testów usługi (z korzenia klonu):
  `node ../orkiestrator/klient/orkiestrator.mjs uruchom --maszyna dowolna --klasa testy --sesja pawel21 --repo hacknation --konto hackathon --ssh --wyslij . -- sh -c '. ~/venv/bin/activate && python -m unittest discover -s usluga/testy -t . -v'`
  Testy strony: ta sama komenda z `-- sh -c 'node --test strona/testy/'`.

## Review Focus

1. Plik nie-BMP albo ucięty → 400 z opisem po polsku, usługa żyje dalej (test w Task 2).
2. Dwa wgrania naraz → drugie czeka na blokadę, oba dostają wynik; brak wyścigu na karcie (test w Task 2).
3. Usługa martwa/uśpiona → strona zwraca 503 z „karta uśpiona — uruchom wdroz.sh --usluga”, nie 500 i nie biały ekran (test w Task 3).
4. Plik 50 MB przez stronę → przekazanie strumieniem, bez obcięcia (test: suma bajtów po stronie usługi = wysłane, Task 3).
5. Obraz szerszy niż mini, gdy biblioteka `maly` nieobecna (lokalny Docker) → liczy na mini z polem `uwaga`, nie pada (test w Task 1).

### Task 2: serwer HTTP usługi

**Files:**
- Create: `usluga/serwer.py`
- Test: `usluga/testy/test_serwer.py`

**Interfaces:**
- Consumes: `usluga.rdzen` (Task 1).
- Produces: `python -m usluga.serwer [--host 0.0.0.0] [--port 8770] [--bezczynnosc 10] [--bez-sieci] [--metoda/--siatka/--szer-rob] [--biblioteki mini,mini-trudny,maly]`; w kodzie `zbuduj(licz, biblioteki, strona_dir, bezczynnosc_s) -> ThreadingHTTPServer` (do testów: `licz(sciezka, nazwa_bib, typ) -> dict`).
- Endpointy (każdy też pod prefiksem `/api`, żeby lokalnie strona działała bez Node):
  - `GET /zdrowie` → 200 `{"ok": urzadzenie=="cuda", "urzadzenie", "karta", "metoda", "siatka", "biblioteki": {nazwa: liczba_wzorcow}}`.
  - `POST /analiza?typ=&biblioteka=` ciało = BMP → 200 wynik `analizuj` + `"biblioteka"`, `"uwaga"?`; nie `BM` na początku / błąd czytania → 400 `{"blad": "to nie jest plik .bmp (…)"}`; ciało > 120 MB → 413.
  - `GET /partia-pokazowa` → 200 `{"wyniki": [...]}` po kolei z `partia-pokazowa.json`.
  - `GET /` i pliki z `strona/public/` (ścieżka spoza katalogu → 403).
- Jedna `threading.Lock` wokół `licz`; zegar bezczynności: po `bezczynnosc_s` bez żądania `shutdown()` (0 = nigdy). `--bez-sieci`: podmiana `socket.socket.connect` odmawiająca adresów spoza 127.0.0.0/8 i ::1 (`OSError("bez sieci")`).

- [ ] **Step 1: testy** (`zbuduj` na porcie 0, `licz`-atrapa, `urllib`):
  - `test_zdrowie`: 200, klucze `ok, metoda, biblioteki`.
  - `test_analiza_bmp`: wysłanie `dane/mini/badany_mini_firanka_czyste_00.bmp` → 200, atrapa dostała plik o tej samej długości bajtów.
  - `test_nie_bmp_400`: ciało `b"PNG..."` → 400, `"bmp" in blad`; zaraz potem `/zdrowie` 200.
  - `test_dwa_naraz`: atrapa śpi 0,3 s i zapisuje chwilę wejścia/wyjścia; dwa wątki → oba 200, przedziały się nie nakładają.
  - `test_bezczynnosc`: `bezczynnosc_s=0.5` → po 1,5 s serwer nie odpowiada.
  - `test_bez_sieci`: po włączeniu straży `socket.create_connection(("1.1.1.1", 80), timeout=1)` rzuca `OSError` z „bez sieci”; `127.0.0.1` do własnego serwera działa.
  - `test_api_prefiks_i_statyczne`: `/api/zdrowie` 200; `/` zwraca `index.html`; `/../usluga/serwer.py` → 403/404.
- [ ] **Step 2:** testy → FAIL. **Step 3:** implementacja. **Step 4:** testy → PASS.
